# BZN-DataPack
# 中文
本项目是我曾为 Minecraft 原版生电服务器制作的数据包，旨在提升玩家在原版游戏中的体验。它会添加一些新配方、恢复仅存在于 Minecraft 老版本中的配方，并加入一些有趣的小成就和莫名其妙的挑战。

# English
This is a datapack I originally made for a vanilla technical Minecraft server to improve the in-game vanilla experience. It adds new recipes, restores recipes that only existed in older Minecraft versions, and includes some fun little advancements and quirky challenges.
