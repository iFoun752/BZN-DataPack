# BZN-DataPack
# 中文
本项目是为我曾经的 Minecraft 原版生电服务器开发的数据包，旨在提升玩家在原版游戏中的体验。它会添加一些新配方、恢复仅存在于 Minecraft 老版本中的配方，并加入一些有趣的小成就和一些莫名其妙的挑战。

版本命名方式:年份+月份+本月第几次更新
例:Ver.26.2.1（2026年2月第1次更新）

# English
This project is a datapack I developed for my former vanilla technical Minecraft server, aimed at improving the vanilla gameplay experience. It adds new recipes, restores recipes that existed only in older Minecraft versions, and includes some fun advancements along with quirky challenges.

Version naming convention: Year + Month + update number for that month
Example: Ver.26.2.1 (1st update in February 2026)
